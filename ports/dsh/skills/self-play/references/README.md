# Retained self-play references

This DSH port retains the upstream reference material needed by its active workflow and removes historical mirrors that the port does not cite.

- `discipline-cases.md` contains worked cases for the self-play disciplines.
- `ground-block-failure.md` records the contamination failure that motivates strict input visibility.
- `measurement-and-reporting.md` distinguishes observations, measurements, failures, and withheld evidence.
- `measurement-bounds.md` states the bounded evaluation contract.
- `dsh-isolation.md` is the DSH overlay for cold-child selection and lifecycle checks.
